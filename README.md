# Trends Wave MSP — Multi-page WordPress-ready starter

Pages included:
- index.html — Home
- about.html — About / Why Us / Process / Client Stories
- services.html — Services with service anchors
- contact.html — Contact form + FAQ demo
- resources.html — Resource / blog listing
- style.css — Shared responsive design + animations
- script.js — Navigation, dropdowns, slider, scroll reveal, back-to-top

## Navigation
- Solutions = full mega menu
- Company = short dropdown
- CSS-drawn chevrons replace the old font glyph, keeping arrows aligned

## Animations
- Scroll reveal animations
- Staggered service/resource cards
- Floating dashboard cards
- Dashboard glow
- Security status pulse
- Network line pulse
- Button/card hover motion
- Mobile menu transitions
- Reduced-motion support via prefers-reduced-motion

## WordPress conversion
This is still static HTML for design approval. Next, it can be converted into a custom WordPress theme with header.php, footer.php, front-page.php, page templates, functions.php, enqueueing, menus, CPTs/ACF and dynamic site settings.
